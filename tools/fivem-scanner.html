FIVEM SERVER SCANNER

Phase City — Currently unavailable

TOOL OFFLINE

FiveM changed their API — this tool is temporarily unavailable.

The Server Scanner and Find Player features both relied on FiveM’s public servers-frontend.fivem.net endpoints, which have been decommissioned by Cfx.re. Requests to the legacy paths now return 404 not found regardless of the client, proxy, or headers used.

We’ll restore the tool if and when a stable replacement endpoint becomes available. In the meantime:

  • To find a player or check server status, ask in the Phase City Discord.
  • To browse public servers, use the official Cfx.re server browser.
